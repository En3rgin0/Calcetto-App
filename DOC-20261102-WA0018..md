# Calcetto Club — setup

App mobile (PWA) in un solo file: `calcetto-club.html`.

## 1. Provala subito (modalità demo)
Apri il file nel browser del telefono o del PC. Senza Firebase configurato funziona in demo:
il "login Google" è simulato e i dati restano sul dispositivo.

## 2. Attivare login Google e database condiviso (Firebase, gratuito)
1. Vai su https://console.firebase.google.com → **Aggiungi progetto**.
2. **Build → Authentication → Inizia → Google → Abilita**.
3. **Build → Firestore Database → Crea database** (modalità produzione).
4. **Impostazioni progetto → Le tue app → Web (</>)**: copia l'oggetto `firebaseConfig`
   e incollalo in `FIREBASE_CONFIG` all'inizio dello script di `calcetto-club.html`.
5. In **Authentication → Impostazioni → Domini autorizzati** aggiungi il dominio dove pubblichi l'app.
6. In **Firestore → Regole** incolla il contenuto del file [`firestore.rules`](firestore.rules)
   (oppure, con la Firebase CLI: `firebase deploy --only firestore:rules`).

### Aggiornare un'app già pubblicata (nuove regole di sicurezza)
Le nuove regole chiudono tre falle: prima chiunque fosse loggato poteva vedere tutte le leghe ed entrarci senza codice,
aggiungere giocatori a leghe altrui e leggere l'email di tutti. Ora:
- l'ingresso funziona solo con il codice giusto (i codici stanno nella collezione `codes`);
- una lega e i suoi dati li vedono solo i membri;
- il profilo (con l'email) lo legge solo il proprietario;
- le carte (foto, icona, soprannome) vengono controllate prima del salvataggio.

Ordine consigliato:
1. Pubblica la nuova versione dell'app **e** le nuove regole insieme.
2. Ogni admin apra l'app una volta: le leghe già esistenti registrano da sole il proprio codice invito.
   Finché l'admin non l'ha aperta, il vecchio codice di quella lega non funziona.
3. Da **Impostazioni lega → Genera nuovo codice** l'admin può cambiare il codice quando vuole
   (utile dopo aver rimosso qualcuno che non deve rientrare).

## 3. Pubblicarla e installarla sul telefono
Carica tutta la cartella `calcetto/` (index.html, sw.js, manifest e icone) su Firebase Hosting, Netlify o GitHub Pages.
Il service worker (`sw.js`) rende l'app installabile e apribile anche senza rete; se lo modifichi, aumenta `VERSION`.
Dal telefono: apri il link → menu del browser → **Aggiungi a schermata Home**.

## Come si calcola l'overall (64 → 99)
- Parte da **64** (nessuna partita) e arriva a **99** al massimo.
- Rendimento = 35% vittorie (pareggio = mezza vittoria) + 35% gol/partita (2 a partita = massimo) + 30% assist/partita (1,2 a partita = massimo).
- Il rendimento pesa di più man mano che si giocano partite (piena affidabilità a 10) e l'esperienza dà un bonus fino a 40 partite.
- Si ricalcola da solo a ogni partita salvata, modificata o eliminata. La formula è in `calcOverall()`.

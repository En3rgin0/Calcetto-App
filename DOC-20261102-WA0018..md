# Calcetto Club — setup

App mobile (PWA) in un solo file: `calcetto-club.html`.

## 1. Provala subito (modalità demo)
Apri il file nel browser del telefono o del PC. Senza Firebase configurato funziona in demo:
il "login Google" è simulato e i dati restano sul dispositivo.

## 2. Attivare login Google e database condiviso (Firebase, gratuito)
1. Vai su https://console.firebase.google.com → **Aggiungi progetto**.
2. **Build → Authentication → Inizia → Google → Abilita**.
3. **Build → Firestore Database → Crea database** (modalità produzione).
4. **Impostazioni progetto → Le tue app → Web (</>)**: copia l'oggetto `firebaseConfig`
   e incollalo in `FIREBASE_CONFIG` all'inizio dello script di `calcetto-club.html`.
5. In **Authentication → Impostazioni → Domini autorizzati** aggiungi il dominio dove pubblichi l'app.
6. In **Firestore → Regole** incolla:

```
rules_version = '2';
service cloud.firestore {
  match /databases/{db}/documents {
    function isMember(l) { return request.auth.uid in get(/databases/$(db)/documents/leagues/$(l)).data.memberIds; }
    function isAdmin(l)  { return request.auth.uid in get(/databases/$(db)/documents/leagues/$(l)).data.admins; }

    match /users/{u} { allow read: if request.auth != null; allow write: if request.auth.uid == u; }

    match /leagues/{l} {
      allow read: if request.auth != null;                       // serve per cercare via codice invito
      allow create: if request.auth != null;
      allow update: if isAdmin(l)
        || (request.auth != null && request.resource.data.diff(resource.data).affectedKeys().hasOnly(['memberIds'])
            && request.auth.uid in request.resource.data.memberIds);   // unirsi con codice
      match /members/{m} {
        allow read: if isMember(l);
        allow create: if request.auth != null;
        allow update: if isAdmin(l) || request.auth.uid == m;
      }
      match /matches/{x} { allow read: if isMember(l); allow write: if isAdmin(l); }
    }
  }
}
```

## 3. Pubblicarla e installarla sul telefono
Carica `calcetto-club.html` (rinominandolo `index.html`) su Firebase Hosting, Netlify o GitHub Pages.
Dal telefono: apri il link → menu del browser → **Aggiungi a schermata Home**.

## Come si calcola l'overall (64 → 99)
- Parte da **64** (nessuna partita) e arriva a **99** al massimo.
- Rendimento = 35% vittorie (pareggio = mezza vittoria) + 35% gol/partita (2 a partita = massimo) + 30% assist/partita (1,2 a partita = massimo).
- Il rendimento pesa di più man mano che si giocano partite (piena affidabilità a 10) e l'esperienza dà un bonus fino a 40 partite.
- Si ricalcola da solo a ogni partita salvata, modificata o eliminata. La formula è in `calcOverall()`.
